## 4. ข้อจำกัดและสิ่งที่ต้องรู้

1. **กล้องยังไม่ได้ทดสอบกับคนจริง** — pipeline จับท่า/นับครั้งไม่ได้แก้ (แก้เฉพาะหน้าตา) และ test เดิมของ pipeline ผ่านหมด แต่ควรลองเล่น 1 รอบบนเครื่องที่มีกล้อง
2. **dev server ที่เปิดค้างไว้ (port 3000) ต้อง restart** — มันเปิดก่อนที่ worktree นี้จะมี `.env` จึงไม่มี `DATABASE_URL` (เป็นสาเหตุของ error "Environment variable not found: DATABASE_URL" ในภาพที่ส่งมา) ปิดแล้วรัน `bun run dev` ใหม่
3. **ฐานข้อมูลแยกของ worktree** — `.env` ของ worktree นี้ (ไม่ถูก commit) ชี้ไปที่ `ai_physio_kids` และ `ai_physio_kids_test` ใน Postgres ตัวเดิม เพื่อไม่ให้ migration/seed ไปลบข้อมูลของ checkout หลัก
4. **Integration test หนึ่งตัวมีอาการ flaky** — "clinician summary lists plateaued patients" บางครั้งได้ `Can't reach database server` ระหว่างยิง query พร้อมกันจำนวนมากผ่าน Docker บน Windows (เกิดตั้งแต่ก่อนแก้โค้ดในรอบแรก) รันซ้ำแล้วผ่าน 5/5 ครั้ง
5. **ฟีเจอร์ที่ตัดออก/ยังไม่มีหน้าจอ**
   - หน้าแก้แผน (`doctor-plans`) ของผู้เชี่ยวชาญถูกลบ เพราะคุณครูเป็นคนให้ภารกิจ · การบันทึก "ผลลัพธ์เมื่อจบชุด" (ใช้สอนโมเดลพยากรณ์) ยังทำได้ทาง API แต่ไม่มีหน้าจอแล้ว
   - เด็กไม่มีแชทและผู้ช่วย AI แบบสนทนา (ตั้งใจ) — ข้อความเป็นของผู้ใหญ่เท่านั้น
   - ท่า "เอียงลำตัว" และ "บิดลำตัว" ยังเป็น DRAFT (แหล่งอ้างอิงยังไม่ยืนยัน) จึงยังให้เป็นภารกิจไม่ได้ จนกว่าผู้เชี่ยวชาญจะตรวจ
6. **ค่ามุมเป้าหมายมาจากผู้ใหญ่** — ยังไม่ได้ปรับสำหรับเด็ก ต้องให้ผู้เชี่ยวชาญกำหนด
7. งาน art ที่ยังค้าง: ดู [KIDS-ART-UI.md §12](../KIDS-ART-UI.md)
