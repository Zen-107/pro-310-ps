## 1. แนวทางใหม่ของแอป (อ่านก่อนวาด)

| เดิม | ใหม่ |
|------|------|
| กายภาพบำบัด **เพื่อรักษา** หลังบาดเจ็บ | ยืดเหยียด/ขยับร่างกาย **เพื่อป้องกันและดูแล (maintain)** |
| ผู้ใช้คือผู้ป่วยผู้ใหญ่ | ผู้ใช้คือ **เด็กประถม อายุ 7–12 ปี** |
| โทน clinical (slate + teal) | โทน **สดใส ขี้เล่น อบอุ่น** แต่ยังอ่านง่าย |
| "ผู้ป่วย", "แผนรักษา", "กายภาพ" | "นักผจญภัย", "ภารกิจ", "ยืดเหยียด", "เล่น" |

**ห้าม** มีภาพหรือคำที่สื่อว่าแอปรักษาโรค (ไม่มีโรงพยาบาล เข็มฉีดยา ผ้าพันแผล ไม้ค้ำ รถเข็น)
ข้อความทางการแพทย์/ข้อจำกัดต่าง ๆ เป็นของ **ผู้ปกครองและครู** ไม่ใช่ของเด็ก

## 2. ผู้ใช้

- **เด็ก (ผู้เล่นหลัก)** อายุ 7–12 ปี อ่านภาษาไทยได้แต่ยังไม่คล่อง ใช้แท็บเล็ต/มือถือของผู้ปกครอง หรือคอมพิวเตอร์ที่โรงเรียน
- **ผู้ปกครอง** ยินยอมแทนเด็ก ดูความก้าวหน้า ให้น้องเล่นที่บ้าน
- **คุณครู** สร้างห้อง พิมพ์บัตรให้เด็ก ให้ภารกิจ ดูทั้งห้อง
- **ผู้เชี่ยวชาญ** (นักกายภาพ/อาจารย์) ดูแลคลังท่า ตรวจรอบที่มีปัญหา

สิ่งที่เด็กต้องทำได้ **โดยไม่ต้องอ่านเยอะ**: เข้าเล่นด้วยรหัส+รูป → รู้ว่าวันนี้มีภารกิจอะไร → กดเล่น → เห็นว่าได้ดาว/สติกเกอร์

## 3. มาสคอต — "น้องยืด" (Yued)

ตัวละครออริจินัลของโปรเจกต์ (ห้ามใช้หรือเลียนแบบตัวการ์ตูนที่มีลิขสิทธิ์) · โค้ด: `src/components/kids/mascot.tsx` · ภาพ: [qa/screens/02-mascot.png](qa/screens/02-mascot.png)

- **รูปร่าง**: ก้อนโมจิกลมนุ่ม สัดส่วนจิบิ (ตัว = หัว) แขนขาสั้นเหมือนแคปซูล มี **ใบไม้ต้นอ่อน 2 ใบ** บนหัว (สัญลักษณ์ "โตขึ้นทุกวัน")
- **สีตัว**: ตามอวาตาร์ของเด็ก (ด้านล่าง) ค่าเริ่มต้นส้มพีช `#FFB38A` ท้อง `#FFE7D6` · แก้ม `#FF8FA8` · ใบไม้ `#6CCB8A` เส้นใบ `#3E9E62`
- **หน้า**: ตาโตสีเข้มมีประกาย 2 จุด (ใหญ่บนขวา เล็กล่างซ้าย) ปากรูป "w" แบบแมว ไม่มีจมูก มีไฮไลต์มันวาวบนหัวซ้าย
- **เส้นขอบ**: `#3B2A4A` หนา 6 (viewBox 240) ปลายมนทุกเส้น · เงาวงรีจาง ๆ ใต้เท้า
- **การเคลื่อนไหว**: ใบไม้แกว่ง 3 วิ · กะพริบตาทุก 4.5 วิ · โยกขึ้นลง (`kids-bob`) · ปิดทั้งหมดเมื่อผู้ใช้ตั้ง reduced motion

| mood | ใช้ตอน | ท่าทาง |
|------|--------|--------|
| `happy` | ทั่วไป หัวจอ | ยิ้ม ยกมือขวา |
| `wave` | ทักทาย หน้าเข้าสู่ระบบ บ้าน | โบกมือขวา ปากเปิดยิ้ม |
| `cheer` | ทำครบ ได้ดาว ฉลอง | แขนชูสองข้าง ตา ^ ^ มีดาวรอบตัว |
| `stretch` | ก่อนเล่น เลือกภารกิจ โหลดกล้อง | ตัวยืดสูง แขนชูเหนือหัว |
| `sleepy` | ไม่มีภารกิจ พัก รอความยินยอม | ตาปิด มี "z z" |
| `think` | โหลด ผิดพลาด รหัสผิด ท่าคลาด | มือแตะคาง มี "?" สีม่วง |

### น้องยืดของฉัน — แต่งตัวได้ (`kids/kids-wardrobe.tsx`, `src/lib/mascot-look.ts`)

เด็กแต่ละคนแต่งน้องยืดของตัวเองในแท็บ **แต่งตัว** แล้วน้องยืดชุดนั้นไปโผล่ทุกที่ (บ้าน ตารางห้องเรียนของครู หน้าลูกของผู้ปกครอง แชท)
เก็บใน `Patient.avatar` เป็น `สี.ตา.ปาก.หมวก.ชุด.แว่น` เช่น `sky.star.grin.cap.scarf.none` (ค่าเก่าแบบสีอย่างเดียว เช่น `peach` = ชุดเริ่มต้น)

| ส่วน | ตัวเลือก (ตัวเลข = ต้องเล่นครบกี่รอบถึงปลดล็อก) |
|------|----------|

| ตา | ตาแป๋ว · ตายิ้ม · ตาจุด · ขยิบตา · ตาดาว (3) · ตาหัวใจ (6) |
| ปาก | ปากแมว · ยิ้มกว้าง · ปากโอ · แลบลิ้น · ฟันกระต่าย (2) |
| หมวก | ไม่ใส่ · โบว์ · ดอกไม้ · ผ้าคาดหัว · หมวกแก๊ป (1) · หมวกปาร์ตี้ (5) · มงกุฎ (10) |
| ชุด | ไม่ใส่ · ผ้าพันคอ · หูกระต่าย · เหรียญทอง (7) · ผ้าคลุมฮีโร่ (15) |

- ของที่ล็อกแสดงเป็นสีเทา + ป้ายกุญแจ แตะแล้วบอกว่า "เล่นอีก N รอบ" (เซิร์ฟเวอร์ตรวจซ้ำใน `PUT /api/me/avatar`)
- หมวกแก๊ป/ปาร์ตี้/มงกุฎ ครอบหัว จึงซ่อนใบไม้ · ท่าทางอารมณ์แรง (cheer, sleepy, think, wave) เปลี่ยนตา/ปากชั่วคราว แล้วกลับเป็นแบบที่เด็กเลือก
- **แตะน้องยืดแล้วมีรีแอค** (`kids/playful-mascot.tsx`): ตัวยุบ-กระโดด เปลี่ยนหน้า พูดประโยคสั้น มีหัวใจ/ดาวกระจาย และโบกมือเองทุก ~9 วินาที · ผู้ใช้ตั้ง reduced motion = เปลี่ยนหน้า+คำพูดอย่างเดียว
- ถ้าวาดของใหม่: ส่ง SVG ที่วางบน viewBox 240 เดียวกับตัวหลัก ขอบ `#3B2A4A` หนา 4–5

ตอนนี้น้องยืดวาดด้วย SVG ในโค้ด (ใช้งานได้จริง) — ถ้านักวาดทำเวอร์ชันละเอียดกว่า ส่งตาม **ข้อ 10** โดยคงสัดส่วนและสีด้านบน

## 4. สี (Color tokens)

กำหนดใน `.theme-kids` (`src/app/globals.css`) — ใช้ชื่อ token ในโค้ด อย่าใส่ hex ตรง ๆ ใน component

| Token | Hex | ใช้กับ |
|-------|-----|--------|
| `--kids-sky` (primary) | `#3BA7F5` | ปุ่มหลัก ลิงก์ แท็บที่เลือก |
| `--kids-sky-deep` | `#1F7FCC` | ขอบล่างปุ่มหลัก (เงา 3D) ข้อความบนพื้นฟ้าอ่อน |
| `--kids-sun` | `#FFC93C` | ดาว ไฟ streak ไฮไลต์ |
| `--kids-grass` | `#4CC38A` | สำเร็จ ✓ ภารกิจเสร็จ |
| `--kids-coral` | `#FF7A6B` | ปุ่ม "เล่นเลย!" ตัวเด่นที่สุดของจอ |
| `--kids-grape` | `#9B7BEA` | สติกเกอร์ หมวดพิเศษ |
| `--kids-ink` | `#3B2A4A` | ตัวอักษรหลัก เส้นขอบ illustration |
| `--kids-paper` | `#FFF8EC` | พื้นหลังจอ (ครีมอุ่น ไม่ใช่ขาวล้วน) |
| `--kids-card` | `#FFFFFF` | การ์ด |

กฎ:
- ตัวอักษรบนพื้น ใช้ `--kids-ink` เสมอ (contrast ≥ 4.5:1) **ห้าม** ใช้ตัวหนังสือสีเหลืองบนพื้นขาว
- ตัวอักษรบนปุ่มสี ใช้ขาว + น้ำหนัก bold และปุ่มต้องสูงพอ (ดูข้อ 6) — ปุ่มเหลืองใช้ตัวอักษร `--kids-ink`
- สีบอกสถานะต้องมี **ไอคอนคู่กันเสมอ** (✓ / ⭐ / 🔒) เผื่อเด็กตาบอดสี
- ยังไม่มีโหมดมืดสำหรับเด็ก (ตั้งใจ — ใช้กลางวัน เด็กใช้คู่ผู้ใหญ่)
- หน้าผู้ใหญ่ใช้ `.theme-adult`: palette เดียวกันแต่พื้น `#FFFAF2` ตัวอักษรขนาดปกติ หัวข้อ Mali เนื้อหา Sarabun ปุ่มหลักสีฟ้า `--kids-sky-deep` (ให้เด็กกับผู้ใหญ่รู้สึกเป็นแอปเดียวกัน แต่ผู้ใหญ่อ่านข้อมูลได้แน่นกว่า)

## 5. ตัวอักษร

- **ฟอนต์หลัก**: [Mali](https://fonts.google.com/specimen/Mali) (Google Fonts, OFL, มีภาษาไทย) — กลม อ่านง่าย มีหัวกลมแบบที่เด็กเรียนในโรงเรียน โหลดผ่าน `next/font` ในชื่อ `--font-mali`
- น้ำหนักที่ใช้: 500 (ข้อความ), 700 (หัวข้อ ปุ่ม)
- ขนาดขั้นต่ำ: ข้อความ **18px**, หัวข้อหน้า **28–32px**, ปุ่มหลัก **22px**
- line-height ≥ 1.6 (ภาษาไทยมีวรรณยุกต์บน/ล่าง)
- ประโยคละไม่เกิน ~10 คำ ใช้คำว่า "เรา" / ชื่อเล่นเด็ก ไม่ใช้ "คุณ" หรือ "ผู้ป่วย"

## 6. รูปทรง ปุ่ม และระยะ

- มุมโค้ง: การ์ด `28px`, ปุ่ม `999px` (pill), ไอคอนในวงกลม
- **ปุ่ม 3D**: พื้นสี + ขอบล่าง 5px สีเข้มกว่า; ตอนกด เลื่อนลง 4px และขอบล่างเหลือ 1px (class `kids-btn` ใน globals.css)
- Touch target ≥ **56×56px** (เด็กนิ้วยังไม่แม่น) ระยะห่างระหว่างปุ่ม ≥ 12px
- 1 จอ = **1 ปุ่มหลัก** สีปะการัง (`--kids-coral`) เท่านั้น
- การ์ดมีเงานุ่ม `0 6px 0 rgba(59,42,74,.08)` (เงาทึบด้านล่าง ไม่ blur มาก ให้ดูเป็นของเล่น)

## 7. ไอคอนและภาพประกอบ

- ไอคอน UI ใช้ **lucide-react** (เส้น 2.5px) ใส่ในวงกลมสีพาสเทล
- ภาพประกอบ: flat + เส้นขอบ `--kids-ink` มน ไม่มี gradient ซับซ้อน ไม่มีเงาสมจริง
- ท่าออกกำลังกาย (`exercise-demo.tsx`) ใช้หุ่นเส้นเดิม — งาน art รอบหน้าให้วาดเป็น **น้องยืดทำท่า** แทนหุ่นเส้น
- ห้ามใช้รูปถ่ายเด็กจริงในแอปหรือสื่อโปรโมต (ดูข้อ 11)

## 8. ระบบรางวัล (Gamification)

ภาษาเด็ก แทนคำเดิมในระบบ:

| ในระบบ (DB/API) | เด็กเห็น |
|----------------|---------|
| Quest | ภารกิจ |
| Session | รอบเล่น |
| Accuracy % | ดาว ⭐ 1–3 ดวง (≥85% = 3, ≥60% = 2, อื่น ๆ = 1) |
| Streak | ไฟ 🔥 ติดกัน X วัน |
| Badge | สติกเกอร์ (สมุดสะสมสติกเกอร์) |

- **ไม่แสดงตัวเลข % หรือกราฟ** ให้เด็กเห็น (ไว้หน้าผู้ปกครอง)
- ไม่มีการลงโทษ: พลาดวันก็ไม่ขึ้นสีแดง ไม่ขึ้นคำว่า "ล้มเหลว" ใช้ "พรุ่งนี้มาเล่นกันใหม่นะ"
- ไม่มี leaderboard เทียบกับเด็กคนอื่น

## 10. ส่งไฟล์ art (Asset delivery)

วางไฟล์ไว้ที่ `public/kids/` ตามชื่อนี้ (SVG ก่อน ถ้าไม่ได้ใช้ PNG @2x พื้นโปร่งใส)

```
public/kids/
├── mascot/
│   ├── yued-happy.svg       # 240×240 viewBox
│   ├── yued-cheer.svg
│   ├── yued-stretch.svg
│   ├── yued-sleepy.svg
│   ├── yued-think.svg
│   └── yued-wave.svg
├── stickers/
│   └── <badge-id>.svg       # 160×160, ตามตารางข้อ 8 (8 ไฟล์)
├── exercises/
│   └── <exercise-slug>.svg  # น้องยืดทำท่า ท่าละ 1 ภาพ (ดู slug ใน exercises-data.ts)
└── bg/
    └── home-hills.svg       # พื้นหลังเนินเขา/ท้องฟ้า ด้านล่างจอบ้าน 1440×320
```

- SVG: outline เป็น path แล้ว (ไม่มี font), ไม่มี embedded raster, ขนาดไฟล์ ≤ 30KB/ชิ้น
- ใช้สีตาม palette ข้อ 4 เท่านั้น (ให้โค้ดเปลี่ยนสีภายหลังได้)
- แหล่งไฟล์ต้นฉบับ (Figma/AI) แนบลิงก์ไว้ท้ายเอกสารนี้

## 11. ความปลอดภัยและความเป็นส่วนตัวของเด็ก

- ภาพจากกล้องประมวลผล **บนเครื่อง** (MediaPipe) ส่งออกแค่จุด landmark — ข้อความบอกเด็ก: "กล้องแค่ดูท่า ไม่ได้ถ่ายรูปหนูไปไหน"
- การอัดวิดีโอต้องได้รับความยินยอมจาก **ผู้ปกครอง** (หน้าจอผู้ปกครอง) ไม่ใช่เด็กกดเอง
- ไม่มีแชทเปิดระหว่างเด็กกับคนแปลกหน้า — แท็บข้อความถูกเอาออกจากหน้าจอเด็ก
- ไม่มีโฆษณา ไม่มีการซื้อในแอป
