# 0005 — ผู้เชี่ยวชาญให้ภารกิจเด็กรายคนได้

- **วันที่:** 2026-11-04
- **ใครสั่ง:** เจ้าของบอกให้บัญชีผู้เชี่ยวชาญกดเพิ่มภารกิจให้เด็กได้
- **ขอบเขตที่ Claude เลือก:** ให้ภารกิจเด็กรายคน ไม่ได้ให้จัดการห้องเรียน
- **สถานะ:** ใช้งานแล้ว API ผ่านเทสต์ แต่หน้าจอยังไม่ได้ลองกดจริง (ดูหัวข้อ "ตรวจแล้ว")
- **เปลี่ยนจากเดิม:** แผนแรกของเวอร์ชันเด็กกำหนดว่า "ครูเท่านั้นที่ให้ภารกิจ" ตอนนี้เป็นครูกับผู้เชี่ยวชาญ

## ทำอะไร

**หน้าจอ:** ผู้เชี่ยวชาญเข้าแท็บ **เด็ก** แล้วเลือกเด็ก จะเห็นการ์ด **"ภารกิจของ…"** ต่อจากการ์ดข้อมูลเด็ก ในการ์ดมี:

- **รายการภารกิจที่กำลังใช้อยู่:** บอกว่าใครให้ และแยกว่าเป็นชุดของห้อง (ครูเป็นคนแก้) หรือให้รายคน
- **ปุ่ม "ให้ภารกิจ":** เปิดฟอร์มเดียวกับของครู เลือกท่าจากคลัง 5 ท่า ตั้งจำนวนรอบ จำนวนครั้ง และวัน แล้วกด "ให้ภารกิจเด็กคนนี้"
- **ปุ่ม ✕:** เลิกภารกิจที่ให้รายคน ประวัติที่เด็กเล่นไปแล้วยังอยู่

**สิทธิ์ใน API (`src/lib/roles.ts`):**

| ทำอะไร | ครู | ผู้เชี่ยวชาญ |
|---|---|---|
| สร้างห้อง เพิ่มเด็ก พิมพ์บัตร รีเซ็ตรหัส (`ASSIGNERS`) | ✅ | ❌ |
| ให้ชุดภารกิจทั้งห้อง | ✅ | ❌ |
| ให้ภารกิจเด็กรายคน (`PLAN_EDITORS`) | ✅ | ✅ **ใหม่** |
| แก้หรือเลิกภารกิจรายคน | ✅ | ✅ **ใหม่** |
| แก้หรือเลิกภารกิจที่มาจากชุดของห้อง | ✅ | ❌ ได้ 403 |

ผู้เชี่ยวชาญยังให้ภารกิจได้เฉพาะเด็กที่ตัวเองดูแลอยู่ (มี CareAssignment) เหมือนการเข้าถึงข้อมูลเด็กอื่น ๆ

## ทำไมไม่ให้ผู้เชี่ยวชาญแก้ชุดของห้อง

ชุดภารกิจของห้องคือชุดเดียวที่คัดลอกให้เด็กทุกคนในห้อง (`classroomId`) ครูแก้ทีเดียวได้ทั้งห้อง ถ้าผู้เชี่ยวชาญแก้ที่เด็กคนหนึ่ง สำเนาของเด็กคนนั้นจะไม่ตรงกับเพื่อน และครูจะสับสนว่าทำไมเด็กคนนี้ไม่เหมือนคนอื่น

ถ้าผู้เชี่ยวชาญอยากให้เด็กคนนี้ทำเพิ่ม ก็ให้ภารกิจรายคนเป็นอีกชุดแยกได้ เด็กจะเห็นภารกิจทั้ง 2 ชุดในวันนั้น

**ทางที่ไม่เลือก:**

- **ให้ผู้เชี่ยวชาญแก้ได้ทุกอย่างเหมือนครู:** ง่ายกว่า แต่ชุดของห้องจะแตกเป็นหลายแบบ
- **ให้ผู้เชี่ยวชาญแค่ "แนะนำ" แล้วรอครูกดยืนยัน:** ปลอดภัยกว่า แต่ต้องทำระบบอนุมัติเพิ่ม และเจ้าของบอกว่าอยากให้ผู้เชี่ยวชาญกดเพิ่มได้เอง

## ไฟล์ที่เปลี่ยน

- **`src/lib/roles.ts`:** เพิ่ม `PLAN_EDITORS` และ `mayEditPlan()`
- **`src/app/api/prescriptions/**`:**
  - ใช้ `PLAN_EDITORS`
  - กันผู้เชี่ยวชาญแก้ชุดของห้อง
  - DTO ส่ง `classroomId` ออกมาด้วย
- **`src/components/teacher/assign-form.tsx`:** ฟอร์มเดียวกันใช้ได้ทั้งให้ทั้งห้อง (`classroomId`) และให้เด็กรายคน (`patientId`)
- **`src/components/expert/kid-missions-card.tsx`:** การ์ดใหม่ ใช้ในหน้าข้อมูลเด็กของผู้เชี่ยวชาญ

## ยังไม่แน่ใจ (ต้องช่วยกันคิด)

1. **ครูควรรู้ไหมว่าผู้เชี่ยวชาญเพิ่มภารกิจให้เด็กในห้อง:** ตอนนี้ภารกิจรายคนนับรวมในตารางวันนี้ของครูอยู่แล้ว แต่ไม่มีแจ้งเตือน ถ้าต้องการ เพิ่มข้อความแจ้งครูได้
2. **ภารกิจซ้ำกัน:** ถ้าครูกับผู้เชี่ยวชาญให้ท่าเดียวกันในวันเดียวกัน เด็กจะเห็น 2 ภารกิจของท่าเดียวกัน ยังไม่ได้รวมหรือเตือน
3. **ผู้ปกครองควรให้ภารกิจลูกเองได้ไหม:** ตอนนี้ยังไม่ได้

## ตรวจแล้ว

- **`bun run qa` ผ่านครบ** มีเทสต์ integration ใหม่ ตรวจว่า:
  - ผู้เชี่ยวชาญสร้างภารกิจรายคนได้ (201) เพิ่มท่าได้ และเลิกได้
  - ผู้เชี่ยวชาญแก้ชุดของห้องไม่ได้ (403) ทั้งเพิ่มท่า แก้ชื่อ และเลิก
  - ผู้เชี่ยวชาญยังให้ชุดภารกิจทั้งห้องไม่ได้ (403)
- **ยังไม่ได้ลองกดหน้าจอในเบราว์เซอร์:** ระบบอนุญาตไม่ให้ Claude อ่านรหัสผ่านเดโมผู้ใหญ่จาก `.env` จึงล็อกอินเป็นผู้เชี่ยวชาญไม่ได้ **เจ้าของต้องลองเอง:** ล็อกอิน `pt@demo.aiphysio.local` → แท็บ เด็ก → เลือกเด็ก → ให้ภารกิจ
- **ระหว่างรัน QA รอบหนึ่ง:** เทสต์ integration ล้มเพราะต่อฐานข้อมูลทดสอบ (127.0.0.1:5432) ไม่ติดชั่วคราว รันซ้ำแล้วผ่าน
