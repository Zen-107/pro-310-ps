- สถานะ: กำลังทำ (deploy ยังไม่เสร็จ)
- ที่มา: เจ้าของอยากให้เวอร์ชันเด็ก "เป็นอีกโปรดักต์" และอยากเปิดเช็กจากมือถือตอนอยู่นอกบ้าน โดยเน้นตัวงาน ยังไม่ต้องทำระบบล็อกอินให้ดี

## ทำไม

- **Private repo:** ข้อมูลในโปรเจกต์เกี่ยวกับเด็ก (แม้เป็นข้อมูลสมมติ) และมีรหัสผ่านเดโมอยู่ใน `.env.example` ถ้าเปิด public คนอื่นจะเห็นและเข้าเว็บเดโมได้ เปลี่ยนเป็น public ทีหลังได้ทุกเมื่อ แต่ย้อนกลับไม่ได้ถ้ามีคน clone ไปแล้ว
- **Vercel:** แอปเป็น Next.js ซึ่ง Vercel รองรับตรงที่สุด ได้ https ทันที (กล้องบนมือถือต้องใช้ https) ต่อกับ GitHub แล้ว push = deploy ใหม่อัตโนมัติ
- **Neon:** แอปใช้ Prisma กับ Postgres อยู่แล้ว Neon เป็น Postgres จริง ไม่ต้องแก้ schema และเพิ่มจากหน้า Vercel (Storage) ได้เลย
- **วิดีโอใน `/tmp`:** บน Vercel เขียนไฟล์ได้แค่ `/tmp` ทำให้ฟีเจอร์อัดวิดีโอยังลองได้ แต่ **คลิปจะหายเองเมื่อเซิร์ฟเวอร์เริ่มใหม่** — รับได้สำหรับเดโม ไม่ใช่สำหรับใช้งานจริง
- **ใส่ข้อมูลเดโมเฉพาะตอนฐานว่าง:** seed เดิมลบข้อมูลทั้งหมดก่อนใส่ ถ้ารันทุก deploy สิ่งที่ลองเล่นไว้จะหายทุกครั้งที่ push
- **migrate ผ่าน connection ตรง:** URL หลักของ Neon ผ่านตัวรวม connection (PgBouncer) ซึ่ง Prisma migrate ไม่ควรใช้ สคริปต์ `scripts/deploy-db.ts` จึงใช้ URL แบบไม่ pool ถ้ามี

## หาข้อมูลจากไหน

- ความรู้เดิมของ Claude เรื่อง Vercel / Neon / Prisma (ยังไม่ได้เปิดเอกสารล่าสุดตรวจทุกข้อ — ดูหัวข้อ "ยังไม่แน่ใจ")
- โค้ดในโปรเจกต์: `src/lib/video-storage.ts`, `prisma/seed.ts` (มีตัวกันลบฐาน production อยู่แล้ว), `src/app/login/page.tsx`

## ยังไม่แน่ใจ (ไม่เดา — จะเช็กตอน deploy จริง)

1. **Vercel ใช้สคริปต์ `vercel-build` เองไหม** — จะตั้ง Build Command เป็น `bun run vercel-build` ตรงๆ ในหน้า Vercel แทนการพึ่งว่า Vercel จะเลือกเอง
2. **มีคำสั่ง `bun` ตอน build บน Vercel ไหม** — repo มี `bun.lock` ซึ่งน่าจะทำให้ Vercel ใช้ Bun แต่จะยืนยันจาก build log
3. **ชื่อตัวแปรที่ Neon ใส่ให้** — คาดว่า `DATABASE_URL` และ `DATABASE_URL_UNPOOLED` สคริปต์รองรับ `POSTGRES_URL_NON_POOLING` ไว้ด้วย จะดูจากหน้า env ของ Vercel หลังเพิ่มฐาน
4. **`output: "standalone"` ใน `next.config.ts` มีผลกับ Vercel ไหม** — คาดว่าไม่มีปัญหา จะดูจาก build

## ต้องให้เจ้าของตัดสิน / ทำเอง

- **ใส่ค่าลับใน Vercel (Settings → Environment Variables)** — Claude ไม่พิมพ์รหัสผ่านหรือ secret ลงเว็บแทน:
  - `NEXTAUTH_SECRET` — ค่าสุ่มยาวๆ (สร้างได้ด้วยคำสั่งด้านล่าง) ถ้าไม่ใส่ ล็อกอินบนเว็บจริงจะใช้ไม่ได้
  - `SEED_DEMO_PASSWORD` — รหัสผ่านบัญชีผู้ใหญ่บนเดโม **ถ้าไม่ใส่ จะเป็นค่าเดียวกับใน `.env.example`** ซึ่งใครเห็น repo ก็รู้ ต้องใส่ก่อน deploy ครั้งแรก เพราะ seed รันครั้งเดียวตอนฐานว่าง
  - `NEXTAUTH_URL` — ลิงก์ `https://….vercel.app` ของเดโม (ได้หลัง deploy ครั้งแรก)
- **วิดีโอบนเดโมควรอยู่ถาวรไหม** — ถ้าใช่ ต้องเปลี่ยนไปเก็บบน Vercel Blob (มีโควตาฟรี) และแก้ `video-storage.ts`
- **ข้อมูลเดโมบนเว็บ** — ถ้าอยากเริ่มใหม่ ต้องล้างฐานใน Neon แล้ว redeploy (seed จะรันใหม่เพราะฐานว่าง)
