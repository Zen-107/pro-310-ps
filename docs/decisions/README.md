# บันทึกการตัดสินใจ (Decisions)

กติกาการทำงาน: Claude เป็นคนลงมือทำ ส่วนเจ้าของโปรเจกต์ตรวจ อ่าน ลองเล่น เช็ก และแก้

ทุกครั้งที่ Claude ตัดสินใจเรื่องที่มีผลต่อโค้ดหรือตัวงาน จะเขียนไฟล์ในโฟลเดอร์นี้หนึ่งไฟล์ แต่ละไฟล์บอก:

- **ทำอะไร** และ**ทำไม**
- **หาข้อมูลจากไหน** หรือรู้มาจากอะไร
- **ทางเลือกที่เทียบ** และเหตุผลที่ไม่เลือกทางอื่น
- **ยังไม่แน่ใจ** — สิ่งที่ Claude ไม่เดา จะเขียนค้างไว้พร้อมบอกว่าต้องรู้ไปทำไม เพื่อคิดด้วยกัน
- **ต้องให้เจ้าของตัดสิน** — คำถามที่ Claude ตอบเองไม่ได้
